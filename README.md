Reflection Questions

1. What is the purpose of a color map?

A color map provides the visible surface color and pattern of an object. It makes a material look like wood, brick, stone, or another real surface instead of using only a plain color.

2. What does a normal map simulate?

A normal map simulates small bumps, grooves, and surface details without adding more geometry. It changes how light reacts to the surface and makes it appear more detailed.

3. How does a roughness map affect lighting?

A roughness map controls how shiny or dull a surface looks. Rougher areas reflect light less sharply, while smoother areas can appear more reflective.

4. Which texture improved realism the most and why?

I think the floor texture improved the realism the most because it covers a large part of the scene. Adding the wood color, normal, and roughness maps made the floor look much more realistic than the original plain brown material.

5. What advantages do texture maps have over adding more geometry?

Texture maps can add a lot of visual detail without increasing the number of polygons in the scene. This can make objects look more realistic while keeping the scene simpler and easier to render.
